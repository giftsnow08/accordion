What is roadmap.sh?

We are planning to add more roadmaps, guides, and interactive content. We're also working on integrations with learning platforms.

How is roadmap.sh built?

∨
roadmap.sh is built using modern web technologies. The frontend is built with React and the backend is built with Node.js and Express.

You can create custom roadmaps using our interactive editor. Simply visit the editor, add your topics and content, and save your roadmap.
